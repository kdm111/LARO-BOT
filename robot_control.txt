[0] 기동 — 무엇을 띄울 것인가  (2026-08-19 재편. 여기부터 읽는다)
═══════════════════════════════════════════════════════════════════════

런치를 조각으로 쪼갰다. 팔만 / 카메라만 / 전체를 골라서 띄운다.
전부 컨테이너 안에서 돈다. 호스트에서 여는 방법은 [0-1].

  ┌ 팔        real_arm.launch.py      ros2_control + robot_state_publisher
  │                                   + joint_state_broadcaster
  ├ 카메라    real_camera.launch.py   usb_cam + config/camera_info.yaml
  ├ TF        camera_tf.launch.py     world -> camera_link -> camera_optical_frame
  ├ 인지      perception.launch.py    object_detector
  ├ MoveIt    moveit.launch.py        move_group   ★ 팔이 먼저 떠 있어야 한다
  ├ 스킬      skills.launch.py        skill_server (/pick /place /move_to)
  └ 판단      agent.launch.py         agent
  전체       real.launch.py           위를 전부 얹는다

★★ 안전은 stage가 담당한다. 노드 스위치가 아니다.
   stage:=read  (기본) 팔 컨트롤러가 없다 -> 무엇이 떠 있든 팔은 못 움직인다
   stage:=hold        팔 컨트롤러가 붙는다 -> 여기서부터 팔이 움직인다

★★ 순서를 타는 노드는 move_group 하나뿐이다 (2026-08-19 실측).
   robot_description을 10초 안에 못 받으면 죽는다(exit -6). 그 토픽은 팔이 낸다.
   real.launch.py가 TimerAction 8초로 알아서 늦추므로 전체로 띄우면 신경 안 써도 된다.
   조각으로 따로 띄울 때만 팔 -> moveit 순서를 지켜라.

★★ 끄기 전에 팔을 받쳐라. 끄면 토크가 풀려 팔이 그 자리에서 무너진다.
   read 단계도 서보 토크는 켜져 있다("읽기 전용"이지 "흐물흐물"이 아니다).

★★ 제일 중요한 규칙
   아래 명령들은 「기준 자세」를 기억한 상태로 만들어져 있다.
   팔이 그 자세에 있지 않으면, 움직이라고 시킨 관절 말고 다른 관절도 같이 움직인다.
   실제로 2026-08-16에 그 사고가 났다 - joint1만 10도 돌리려 했는데
   joint2가 12도, joint3이 9도 같이 갔다. 파일의 값이 옛 자세였기 때문이다.
   => 움직이기 전에 [1]로 읽어서 「기준 자세」와 같은지 확인해라.
      다르면 명령의 숫자 5개를 읽은 값으로 바꾸거나, 나에게 출력을 붙여 새로 받아라.

[12] 카메라 캘리브 파일  /tmp/camera_info.yaml

★ /tmp 에 있으므로 컨테이너를 재생성하면 사라진다. 없으면 아래를 다시 만들어라.
★ fx = 485 는 2026-08-17 이 웹캠으로 직접 잰 값이다 (가제보의 554 가 아니다).
   재는 법 : 크기를 아는 물건을 카메라와 마주보게 두고, 거리를 재고, 사진에서 픽셀을 센다
     fx = (픽셀 폭 x 거리) / 실제 폭
   이번 실측 : 체크카드(85.6 x 54.0mm, 국제 규격)를 24cm 앞에 두었더니 176 x 107 px
     가로 기준 176 / 85.6 x 240 = 493.5
     세로 기준 107 / 54.0 x 240 = 475.6      -> 평균 485
   검산 : fx=485 면 24cm 에서 화면에 31.7cm 가 담긴다. 눈대중 30cm 와 맞는다.
          화각으로는 가로 66.9도 (가제보 60도보다 조금 넓다. 웹캠으로 자연스러운 값).
   ★ 정밀도 : 거리를 1cm 잘못 재면 fx 가 20 (4%) 움직인다. 지금 24cm 는 눈대중이므로
              이 값도 ±5% 쯤으로 본다. 최종 판정은 단계 3 의 "정답 대조 5mm 이하" 에서 한다.

★★ fx 는 카메라를 어디에 두든 안 바뀐다. 24cm 는 재기 위한 발판이었을 뿐,
   앞으로 그 거리를 지킬 필요가 없다. 카메라를 옮기면 바뀌는 것은 fx 가 아니라
   [11-3] 의 static TF (카메라가 어디에 어떤 각도로 있나) 다.
   fx 가 바뀌는 경우는 : 해상도를 640x480 에서 바꾸거나, 렌즈/카메라를 교체할 때뿐이다.
